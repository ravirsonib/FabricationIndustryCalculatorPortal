## 📖 About the Project

**Fabrication Industry Calculator** is a professional web application built for engineers, manufacturers, fabrication industries, suppliers, and sales teams.

The application replaces manual engineering calculations with quick, accurate, and easy-to-use calculators based on common fabrication industry formulas.

* Fabrication Industries

# 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/fabrication-industry-calculator.git
```

### Navigate to the Project

```bash
cd fabrication-industry-calculator
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

The application will start on:

```bash
http://localhost:5173
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
